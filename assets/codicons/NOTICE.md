# Codicons

The SVG files in this directory are from Microsoft's
[Codicons](https://github.com/microsoft/vscode-codicons) project, commit
`8d1826a9bce0a52283ecaeb63499c149e97a4f14`, `src/icons/`. They are unmodified on
disk; SCM replaces `currentColor` with the Panel's icon colours when it sends
them to Sprite, and shifts the two disclosure chevrons inside their 16-pixel
slots to match where VS Code draws them.
